Programando seus próprios jogos em Lua/Luau:

1. O que é Lua/Luau?

Lua é uma linguagem de programação leve e simples de aprender. Luau é uma versão baseada em Lua, utilizada principalmente no Roblox. Neste tutorial, vamos aprender os conceitos básicos das duas.

2. Seu primeiro código

Para começar, vamos mostrar uma mensagem na tela usando print(). 

print("Olá, mundo!")

O resultado será:

Olá, mundo!

A função print() serve para exibir mensagens ou valores. O texto fica entre aspas.

3. Variáveis: guardando informações

Uma variável funciona como uma caixa onde guardamos um valor para usar depois. 

local nome = "Henrique"
local idade = 17

print(nome)
print(idade)

Usamos local para criar uma variável local. O sinal = atribui um valor a ela. Você pode trocar o nome e a idade pelos seus próprios valores.

4. Tipos de dados

Existem diferentes tipos de informação que podemos guardar: 

local nome = "Ana"       -- Texto (string)
local idade = 18         -- Número
local jogando = true     -- Verdadeiro ou falso (boolean)

print(nome)
print(idade)
print(jogando)

Textos usam aspas, números não precisam delas e valores booleanos podem ser true ou false.

5. Tomando decisões com if

O if permite executar um código somente quando uma condição é verdadeira. 

local idade = 18

if idade >= 18 then
    print("Maior de idade")
else
    print("Menor de idade")
end

Se a condição for verdadeira, o primeiro bloco será executado. Caso contrário, será executado o bloco do else. O end encerra a estrutura.

6. Repetindo ações com loops

Os loops permitem repetir uma ação sem precisar escrever o mesmo código várias vezes. 

for i = 1, 5 do
    print("Número:", i)
end

Esse código mostra os números de 1 até 5. A variável i muda a cada repetição.

7. Criando funções

Uma função reúne instruções que podemos executar sempre que precisarmos. 

local function cumprimentar(nome)
    print("Olá, " .. nome .. "!")
end

cumprimentar("Ana")
cumprimentar("Pedro")

O símbolo .. junta textos. Nesse exemplo, a função recebe um nome e mostra uma saudação.

8. Desafio para praticar

Agora é sua vez! Tente criar um programa que guarde o nome de um personagem, sua vida e mostre se ele ainda está vivo. 

local personagem = "Guerreiro"
local vida = 100

if vida > 0 then
    print(personagem .. " está vivo!")
else
    print(personagem .. " foi derrotado!")
end

Dica: altere o valor de vida para 0 e execute o código novamente para observar a diferença.

Próximos passos

Depois de aprender esses conceitos, você pode estudar tabelas, while, operadores, eventos e criação de scripts no Roblox Studio. Pratique modificando os exemplos e criando pequenos programas.
